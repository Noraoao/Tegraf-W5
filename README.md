## Prerequisite

- Any text editor to save the file
- Any web browser to open the file

## Instructions on running it

- Save the file
- Open the html file in a browser

- Use the Input Type dropdown to switch between Adjacency Matrix and Incidence Matrix modes
- Type in or paste matrix into the Matrix Data text box
- Click Build & Analyze to process input
